# Домашнє завдання: Читання LDR через АЦП на ESP32-S3

Дослідити роботу АЦП ESP32-S3 при зчитуванні напруги з дільника напруги на основі фоторезистора (LDR): порівняти "сирі" (RAW) значення АЦП, самостійно обчислену напругу та напругу, отриману вбудованою функцією `analogReadMilliVolts()`, а також оцінити вплив атенюації та розрядності АЦП на результат.

## Схема підключення
Дільник напруги: LDR підключений між VCC (3.3В) та точкою вимірювання, постійний резистор R (10кОм)— між точкою вимірювання та GND.

```
3.3V ──[LDR]──●──[R]── GND
              │
            ADC_PIN
```

## Що робить код

1. Підключення LDR до ESP32-S3 у вигляді дільника напруги.
2. Зчитування значення АЦП кожні 100 мс.
3. Зчитування RAW-значення через `analogRead()`.
4. Обчислення напруги вручну за формулою.
5. Зчитування напруги через `analogReadMillivolts()` (каліброване значення).
6. Виведення в серійну консоль у вигляді таблиці: RAW, обчислена напруга, напруга з `analogReadMillivolts()`.
7. Обчислення похибки (зі знаком) між обчисленою та каліброваною напругою.
8. Зміна атенюації АЦП через `analogSetPinAttenuation()`.
9. Порівняння результатів при різних атенюаціях та розрядностях АЦП.

## Параметри вимірювань
Виміри проводились для комбінацій:

**Атенюація:**
- `ADC_0db`
- `ADC_6db`
- `ADC_11db`

**Розрядність АЦП:**
- 10 біт (`ADC_STEPS = 1023`)
- 12 біт (`ADC_STEPS = 4095`)
