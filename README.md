# Усунення брязкоту контактів кнопки (debounce)

## Завдання 1 — базова реалізація(без debounce)
- Interrupt на `FALLING`, інкремент лічильника в ISR, вивід у лог

## Завдання 2 — software debounce (time-based)
- Додати debounce на основі часу: ігнорувати interrupt, якщо з моменту попереднього пройшло < 50 мс
- Реалізувати поза ISR

## Завдання 3 — debounce через перевірку рівня (state-based)
- ISR лише ставить прапорець (`CHANGE`)
- `loop()` приймає подію лише якщо пін досі `HIGH`, відпускання ігнорується

## Завдання 4 — polling + FSM (без interrupts)
- Interrupt прибрано, опитування кожні 5-10 мс (`millis()`)
- Debounce як FSM: `IDLE → PRESS_DEBOUNCE → PRESSED → RELEASE_DEBOUNCE → IDLE`

## Завдання 5 — hardware debounce
- RC-фільтр: R = 100 Ом (послідовно), C = 100 нФ (на GND), τ = 10 мкс
- Підходи 1-4 повторені з фільтром на вході
