# Ккласичний Arduino blink у Embedded C++
 
Простий проєкт на Arduino Framework, що керує світлодіодом через кнопку з апаратним перериванням. Кнопка циклічно перемикає режими роботи LED: **блимання → постійно увімкнено → постійно вимкнено → знову блимання**.

Код побудований на неблокуючих таймерах (`millis()` / `micros()`) — без жодного `delay()` в основному циклі, що дозволяє паралельно вимірювати продуктивність `loop()`.

Усі налаштування винесені у `constexpr` на початку файлу.

Кожні `ITERATION_PRINT` (1000) ітерацій `loop()` в Serial Monitor виводиться час, за який вони виконались, у мікросекундах `micros()`
 
 
## Режими роботи LED
 
| Режим | Поведінка |
|---|---|
| `blinking` | LED блимає з періодом `PHASE_TIME` (за замовчуванням — 1 секунда on / 1 секунда off) |
| `alwaysOn` | LED постійно увімкнений |
| `alwaysOff` | LED постійно вимкнений |
 
Кожне натискання кнопки (з урахуванням debounce) перемикає режим на наступний за колом:
 
```
blinking → alwaysOn → alwaysOff → blinking → ...
```

## Кнопка та переривання
 
- `attachInterrupt` на `BUTTON_PIN`, тип `FALLING`.
- ISR мінімальна — лише встановлює `volatile bool buttonPressed = true`, без `Serial.print` і без логіки.
- Уся обробка (debounce + перемикання режиму через `nextMode()`) виконується в `loop()`.
- Debounce: повторні спрацювання ISR ігноруються, якщо з моменту останнього прийнятого натискання минуло менше `DEBOUNCE_TIME` (50 мс) — фільтрує брязкіт контактів.
 
## Технічні деталі реалізації
 
- **Без `delay()`** — весь таймінг побудований на порівнянні `millis()`/`micros()` з попереднім збереженим моментом часу, що дозволяє `loop()` виконуватись без блокувань.
- **`volatile`** для `buttonPressed` — обов'язково, оскільки змінна змінюється всередині ISR і читається в основному потоці; без `volatile` компілятор міг би закешувати старе значення.
- **`enum class`** для `LedState` та `LedMode` — типобезпечні перелічення без неявних перетворень в `int` та без конфлікту імен у глобальному просторі.
- **`IRAM_ATTR`** на ISR — необхідно для ESP32/ESP32-S3, щоб код переривання виконувався зі швидкої внутрішньої пам'яті. Для плат на AVR (Uno, Nano, Mega) цей атрибут можна прибрати.
