# ESP32 Два світлодіоди, зовнішня кнопка та BOOT (ESP32)

Два світлодіоди блимають по черзі, швидкість блимання регулюється двома кнопками.

![Демонстрація](assets/demo.gif)

## Логіка

- Кнопка `BUTTON_OUT` (GPIO 42) — зменшує затримку (пришвидшує блимання)
- Кнопка `BUTTON_IN` (GPIO 0) — збільшує затримку (сповільнює блимання)
- Обидві кнопки одночасно натиснуті — встановлює затримку 1000 мс
- Поточна затримка виводиться в Serial Monitor (115200 baud)

## Піни

| Пін     | Призначення              |
|---------|--------------------------|
| GPIO 41 | Світлодіод (синій)       |
| GPIO 40 | Світлодіод (червоний)    |
| GPIO 42 | Кнопка (INPUT_PULLDOWN)  |
| GPIO 0  | Кнопка BOOT (INPUT_PULLUP) |
