# Керування реле за допомогою таймеру (ESP32)

Реле вмикається кожні 6 секунд на 2 секунди і вимикається автоматично.

## Реалізація

- Апаратний таймер ESP32 (`hw_timer_t`) генерує переривання раз на секунду
- У перериванні лічильник секунд визначає, увімкнено вентилятор чи ні — без `delay()`
- Цикл вмикання/вимикання повністю автономний, `loop()` у ньому участі не бере
- Реле активне по `LOW`, тому в `setup()` виставлено `HIGH` (вимкнено за замовчуванням)
- Watchdog (`esp_task_wdt`) перезавантажує пристрій, якщо основний код зависне
