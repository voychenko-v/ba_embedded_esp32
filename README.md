# Superloop та незалежні задачі — Multi-LED Blinker
 
Керування трьома незалежними світлодіодами в одному `loop()` без блокування.
 
- LED1 блимає кожні 200 мс
- LED2 блимає кожні 500 мс
- LED3 блимає кожні 1000 мс
 
## Реалізація

Кожен світлодіод описаний структурою `BlinkingLed` (пін, інтервал, тривалість спалаху, час останнього спалаху, стан). Усі світлодіоди зберігаються в масиві `leds[]` та обробляються одним циклом `for` у `loop()` — без дублювання коду і без блокуючих викликів.
 
Логіка на кожній ітерації:
1. Якщо світлодіод вимкнений і минув `interval` — увімкнути.
2. Якщо світлодіод увімкнений і минув `flashDuration` — вимкнути.
